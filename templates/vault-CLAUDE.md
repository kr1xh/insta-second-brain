# Second Brain: context

Notes captured from my Instagram saved folders. One note per post or reel.

## Structure

- `00-meta/index.md`: one line per note. Read this first.
- Numbered folders: one per Instagram saved folder.
- `06-inbox/`: unprocessed or uncertain captures.
- `07-drafts/`: my output (emails, plans, scripts). Source notes are never edited from here.

## Rules

- Use [[wikilinks]] between related notes.
- Note name: `Creator - Short Title`.
- Frontmatter: `source`, `creator`, `folder`, `captured`, `tags`.
- Update `00-meta/index.md` whenever notes are added.
- Never delete. If unsure where something goes, put it in `06-inbox/`.
- Ask before overwriting an existing note.
